## 📝 Problem Statement

Explain Merge Sort as a commonly used sorting algorithm. Sort data by dividing it and merging sorted halves. Show the core idea, a concrete example, correctness intuition, implementation, and complexity.

## 💡 Approach: Merge Sort

Merge sort is a classic divide-and-conquer algorithm. It recursively divides the input list into two halves until each sub-list contains a single element (which is inherently sorted). Then, it repeatedly merges these sorted sub-lists to produce new sorted sub-lists until there is only one sorted list remaining containing all elements.

## ⏱️ Complexity

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(n)`
